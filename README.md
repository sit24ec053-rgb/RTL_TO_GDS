
# 8-bit Calculator — RTL to GDS

## Project Overview
An 8-bit combinational calculator designed using
Verilog RTL.

The project aims to demonstrate the complete
digital ASIC design flow from RTL design
to physical layout.

## Features
- Addition
- Subtraction
- AND
- OR
- XOR
- NOT
- Left shift
- Right shift
- Carry, zero and overflow flags
